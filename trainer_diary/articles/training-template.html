Шаблоны тренировок

Создавайте шаблоны, сохраняйте структуру упражнений, используйте теги и повторяйте привычные тренировки.

Что такое шаблон тренировки

Шаблон тренировки — это сохранённая структура занятия, которую можно использовать повторно. В нём можно заранее указать упражнения, подходы, повторения, вес и другие параметры, чтобы не настраивать тренировку каждый раз заново.

Как создать шаблон

Создать шаблон можно одним из трёх способов.

Способ 1. Через кнопку «+» на главном экране

  1. На главном экране нажмите кнопку + в нижнем правом углу.
  2. В открывшемся меню выберите «Создать шаблон».

Способ 2. Через раздел «Шаблоны» на главном экране

  1. На главном экране найдите раздел «Шаблоны».
  2. Прокрутите экран, пока не появится кнопка +, и нажмите её.

Способ 3. Через полный список шаблонов

  1. На главном экране нажмите стрелку справа от названия раздела «Шаблоны».
  2. На открывшемся экране шаблонов нажмите кнопку + в нижнем правом углу.

После открытия редактора укажите название шаблона: поле «Название» обязательно для заполнения. Затем при необходимости добавьте заметки и упражнения, настройте параметры и сохраните шаблон.

Поля шаблона

Название

Помогает быстро найти шаблон в списке и понять, для какой тренировки он предназначен.

Заметки

Дополнительная информация о плане: цель тренировки, порядок выполнения, акценты или другие указания.

Упражнения

Добавьте нужные упражнения и задайте для них структуру подходов, повторений, веса и другие параметры, доступные в редакторе упражнений.

Круговая тренировка

Если нужен круговой формат, ознакомьтесь с руководством «Круговые тренировки».

Теги

Метки для группировки и быстрого поиска шаблонов, например по группе мышц, типу тренировки или тренировочной цели.

Редактирование шаблона

Список упражнений и настройки шаблона редактируются на одном экране. Переключайтесь между разделами «Упражнения» и «Настройки», чтобы изменить нужные параметры.

Способ 1. Из открытого шаблона

  1. Откройте нужный шаблон.
  2. Нажмите кнопку с тремя точками в верхнем правом углу.
  3. Выберите «Редактировать».
  4. В редакторе переключайтесь между разделами «Упражнения» и «Настройки», чтобы внести изменения.

Способ 2. Из списка шаблонов

  1. На экране шаблонов найдите нужную карточку.
  2. Нажмите кнопку с тремя точками в верхнем правом углу карточки.
  3. В открывшемся меню выберите «Редактировать».

Копирование шаблона

Скопировать шаблон можно только на экране шаблонов.

  1. Откройте экран шаблонов.
  2. Найдите карточку шаблона, который хотите скопировать.
  3. Нажмите кнопку с тремя точками в верхнем правом углу карточки.
  4. В открывшемся меню выберите «Копировать».

Копия сразу появится в списке шаблонов. Редактор автоматически не открывается.

При копировании переносятся упражнения, подходы, веса и настройки шаблона. Данные об интенсивности подходов обнуляются. Копируется шаблон целиком — выбрать для копирования только отдельные упражнения нельзя.

Удаление шаблона

Способ 1. Из открытого шаблона

  1. Откройте шаблон, который хотите удалить.
  2. Нажмите кнопку с тремя точками в верхнем правом углу.
  3. Выберите «Удалить». Шаблон будет удалён сразу, без дополнительного подтверждения.

Способ 2. Из списка шаблонов

  1. На экране шаблонов найдите карточку нужного шаблона.
  2. Нажмите кнопку с тремя точками в верхнем правом углу карточки.
  3. В открывшемся меню выберите «Удалить». Шаблон будет удалён сразу, без дополнительного подтверждения.

Как использовать шаблон

Откройте нужный шаблон и нажмите «Создать тренировку». Будет создана тренировка с упражнениями и настройками, заданными в шаблоне. Если нужно назначить её на определённую дату и время, используйте этот способ создания запланированной тренировки.

Работа с тэгами

Добавление тэга в шаблон

  1. На экране редактирования шаблона перейдите в раздел «Настройки».
  2. В разделе «Тэги» нажмите «Добавить».
  3. В открывшемся окне выберите тэг из списка доступных. Чтобы создать новый тэг, нажмите «Добавить».
  4. Укажите название нового тэга и выберите его цвет.
  5. Нажмите галочку в правом верхнем углу, чтобы сохранить тэг.
  6. После сохранения выберите созданный тэг из списка доступных, чтобы добавить его в шаблон.

Фильтрация по тегам

Используйте фильтр тегов в списке шаблонов, чтобы оставить только шаблоны с выбранными метками. Например, можно создать теги для тренировок ног, спины, груди или разделить планы на силовые и объёмные.

Теги помогают организовать собственные шаблоны. Выбирайте понятные названия и используйте одну систему меток, чтобы список оставался удобным.
