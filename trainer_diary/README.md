# Trainer Diary — справка

Статический сайт справочного центра на русском языке с тёмной темой. Не требует Node.js, сборки или сторонних библиотек.

## Структура

- `index.html` — главная страница, поиск, разделы и быстрый доступ.
- `articles/training.html` — страница «Тренировка».
- `articles/training-template.html` — страница «Шаблон тренировки».
- `articles/notifications.html` — инструкция по системным настройкам уведомлений Android.
- `articles/privacy_policy.html` — существующий файл политики конфиденциальности; сохраните его в этой папке при загрузке сайта.
- `assets/styles.css` — стили и адаптивная вёрстка.
- `assets/script.js` — поиск по разделам.

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. После публикации сайт будет доступен по адресу GitHub Pages вашего репозитория.

Если репозиторий называется `username.github.io`, сайт будет доступен на корневом домене. Для обычного репозитория GitHub Pages использует путь `/<имя-репозитория>/`.

## Где менять тексты

Тексты страниц находятся в HTML-файлах. Общий внешний вид редактируется в `assets/styles.css`. Поисковые названия и ключевые слова находятся в `assets/script.js`.
