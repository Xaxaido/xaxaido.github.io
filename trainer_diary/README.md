# Trainer Diary — справка

Статический сайт справочного центра на русском языке. Не требует Node.js, сборки или сторонних библиотек.

## Структура

- `index.html` — главная страница, поиск и три основных раздела.
- `articles/training.html` — раздел «Тренировки» с тремя подразделами.
- `articles/scheduled-training.html` — запланированные тренировки, параметры расписания.
- `articles/training-template.html` — создание и использование шаблонов, заметки и теги.
- `articles/circuit-training.html` — настройка круговых тренировок, интервалов и количества кругов.
- `articles/notifications.html` — системные настройки уведомлений Android.
- `articles/privacy_policy.html` — политика конфиденциальности.
- `assets/styles.css` — общие стили и адаптивная вёрстка.
- `assets/script.js` — поиск с независимым выпадающим списком.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в репозиторий GitHub.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
